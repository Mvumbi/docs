<Steps>
  <Step title="Importez le SDK">
    ```php
    use MaishaPay\MaishaPay;
    ```
  </Step>

  <Step title="Initialisez le client">
    ```php
    $pay = new MaishaPay(
      apiKey: 'mp_live_xxxxxxxx',
      secretKey: 'ms_live_xxxxxxxx',
      environment: Environment::SANDBOX,
    );
    ```

    <Note>
      Utilisez `Environment::SANDBOX` pour tester, `Environment::LIVE` pour la production.
    </Note>
  </Step>

  <Step title="Initiez une collecte Mobile Money avec le builder fluide">
    ```php
    $transaction = $pay->mobileMoney()
      ->amount(500000)
      ->currency('CDF')
      ->phone('+243812345678')
      ->operator('mpesa')
      ->reference('ORDER-001')
      ->execute();
    ```
  </Step>
</Steps>

## Exemple complet (Laravel)

```php
use MaishaPay\MaishaPay;

class PaymentController extends Controller
{
    public function pay(Request $request)
    {
        $pay = new MaishaPay(
            apiKey: config('services.maishapay.api_key'),
            secretKey: config('services.maishapay.secret_key'),
            environment: Environment::SANDBOX,
        );

        $transaction = $pay->mobileMoney()
            ->amount($request->input('amount'))
            ->currency('CDF')
            ->phone($request->input('phone'))
            ->operator('mpesa')
            ->reference(uniqid('ORDER-'))
            ->execute();

        return response()->json($transaction);
    }
}
```

<Tip>
  Stockez vos clés API dans votre fichier `.env` et référencez-les via `config()`, jamais en dur
  dans votre code source.
</Tip>
