---
title: "Démarrage rapide"
description: "Effectuez votre première transaction avec l'API MaishaPay en quelques minutes"
---

Ce guide vous permet d'effectuer votre première requête vers l'API MaishaPay en environnement
Sandbox.

<Steps>
  <Step title="Créez un compte marchand">
    Si ce n'est pas déjà fait, créez un compte sur le
    [dashboard marchand MaishaPay](https://marchand.maishapay.online).
  </Step>

  <Step title="Récupérez vos clés API">
    Depuis votre dashboard, récupérez votre `publicApiKey` et votre `secretApiKey`. Utilisez les
    clés préfixées `MP-SBPK-...` pour le Sandbox, ou `MP-LIVEPK-...` pour la production.

    <Info>
      Ne partagez jamais votre `secretApiKey` publiquement (dépôt Git, code front-end, etc.).
    </Info>
  </Step>

  <Step title="Effectuez un appel de test en Sandbox">
    Initiez une collecte Mobile Money avec `gatewayMode` à `"0"` (Sandbox) :

    ```bash
    curl --location 'https://marchand.maishapay.online/api/collect/v2/store/mobileMoney' \
    --data-raw '{
        "transactionReference": "TEST-001",
        "gatewayMode": "0",
        "publicApiKey": "MP-SBPK-votre_cle_publique",
        "secretApiKey": "MP-SBPK-votre_cle_secrete",
        "order": {
            "amount": "1000",
            "currency": "CDF",
            "customerFullName": "Client Test",
            "customerEmailAdress": "test@email.com"
        },
        "paymentChannel": {
            "channel": "MOBILEMONEY",
            "provider": "AIRTEL",
            "walletID": "+243990000000",
            "callbackUrl": "https://votre-domaine.com/callback"
        }
    }'
    ```

    Une réponse `202` avec `transactionStatus: "PENDING"` confirme que la transaction a bien été
    initiée.
  </Step>

  <Step title="Recevez la notification finale">
    MaishaPay enverra le statut final (`SUCCESS` ou `FAILED`) à l'URL indiquée dans
    `callbackUrl`. Assurez-vous que votre endpoint est accessible publiquement et répond avec un
    code `200`.
  </Step>

  <Step title="Vérifiez le statut à tout moment">
    Utilisez l'endpoint [Transaction Lookup](/api-reference/transactions/lookuptransaction) pour
    interroger le statut d'une transaction, avec votre référence marchand ou l'ID MaishaPay.
  </Step>
</Steps>
